# Personal Portfolio (React)

A responsive single-page portfolio built with **React 18** and **Vite**.

## Sections

- Hero with call-to-action
- About and highlights
- Skills with progress bars
- Project cards
- Contact form (client-side demo)

## Customize

Edit `src/data/portfolio.js` for your name, bio, skills, projects, email, and social links.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

Static files are output to `dist/` and can be deployed to Netlify, Vercel, GitHub Pages, etc.
